# Solana SPL Utility Token

A Scotty Pumpkin **SPL utility token** built to support on-chain applications, ecosystem incentives, and future governance or access-based features.

This repository serves as the **initial reference implementation** and documentation hub for the token.

---

## Overview

This project defines and manages a standard **SPL Token** on the Solana blockchain.  
The token is designed for utility use cases such as:

- Access to platform features
- Incentives and rewards
- Payments within decentralized applications
- Governance or staking (future scope)

The implementation follows Solana and SPL best practices.
